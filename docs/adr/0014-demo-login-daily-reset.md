# 0014: デモログインと日次リセット

- ステータス: 採用(実装前)
- 日付: 2026-11-13

## 採用
- デモは会員登録と同じ経路で本物のユーザーを作り、毎日 4:00 JST にシードの状態へ戻す(migrate:fresh --seed の後に Redis を全消去)。荒らしを見つけたときは、GitHub Actions の workflow_dispatch(reset.yml)から aws ecs run-task で同じコマンドを実行する。
## 理由
- 面接官がアカウントを作らずに全機能を本物の経路で触れるためにでもログイン機能を実装したが、誰でも使えるため荒らし対策が必要なため。
- デモ環境でデータを残す必要がないので日次リセットで対応。
